# job-assistant bot

### Work in progress!

The goal of this project is to have a bot that helps me apply to jobs quicker using AI to fill in all of the gaps in the form but also have the user be involved to avoid TOS problems. Currently in progress, works halfway but not the way that I am happy with yet!


#### Known problems
* Does not work well with dropdowns with pre existing values
* Need to make sure that sonnet has all of the context necessary to fill out these open ended questions.
* No auth currently
* UI for managing profile needs a complete overhaul, barebones right now to just get all the pieces working (includes the extension)
* Still no EEO handling
